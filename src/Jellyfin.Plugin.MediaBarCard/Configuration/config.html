Which version of the media bar to use. Leave as embedded (recommended): the version built into this plugin, tested to match it, works without internet access. Advanced: enter a release number (like 2.4.12.0) to load that exact version from the internet instead.
With this on and Version set to main or latest, the media bar loads the developers' newest work-in-progress from the internet. Changes appear on their own within about half a day, before they have been released or fully tested. If something breaks, turn this off to go back to the built-in version.
